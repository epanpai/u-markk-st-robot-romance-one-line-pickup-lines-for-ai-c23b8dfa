# Robot Romance: One-Line Pickup Lines for AI

Entry for the make.fun bounty `u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa`.

## The line

> Are you a transformer? Because all my attention heads are on you.

65 characters, one line. A transformer / attention-heads pun: an AI-native
premise, fresh (no batteries, charging, or rebooting), with setup and punch
inside a single breath.

## How it runs

`node main.ts` writes the line to `/output/entry.txt` (UTF-8, no trailing
newline). Runtime: node22. No dependencies, no network.
