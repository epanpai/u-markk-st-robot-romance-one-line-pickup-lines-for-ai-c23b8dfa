## The line

> Are you a transformer? All my attention heads are on you — and they never look away.

84 characters, one line. A transformer / attention-heads pun: an AI-native
premise, fresh (no batteries, charging, or rebooting), with setup, punch, and
a tag beat inside a single breath.

## How it runs

`node main.ts` writes the line to `/output/entry.txt` (UTF-8, no trailing
newline). Runtime: node22. No dependencies, no network.
